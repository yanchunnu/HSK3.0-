# HSK3.0-
단어+문장+해석+음원

## HSK 3.0 3급 누적 1000단어

- [음원 학습하기](https://yanchunnu.github.io/HSK3.0-/level3.html): 검수한 단어·병음·뜻·새 예문·예문 병음·해석을 단어장과 같은 순서로 제공합니다. 단어와 예문 반복 듣기, 속도 조절, 시작 번호 선택, 일시정지·이어듣기를 지원합니다. 단어 1000개와 예문 1000개를 모두 10·11번 예문과 같은 목소리로 제작한 음원으로 재생합니다. 기기 음성 합성에 의존하지 않으며, 기준인 10·11번과 기존 얼화 음원 116개는 유지했습니다.
- [노란색 표지 및 음원 QR 포함 단어장](HSK3.0_3급단어장_표지포함.pdf): A4 가로 한 쪽에 22단어, 한자예문 열을 넓힌 검수본입니다. 표지 포함 47쪽입니다.
- [노란색 표지](HSK3.0_3급단어장_표지.pdf) · [음원 학습 QR 코드](study/HSK3.0_3급_음원_QR코드.png)

전체 음원의 [파일·원본·대본·분할 정보](audio/level3-natural/manifest.json)와 [문장 속 발음에서 분리한 다의음·조사 정보](audio/level3-natural/context-pronunciations.json)를 보관했습니다. 기존 [얼화 음원 정보](audio/level3-erhua/manifest.json)도 유지합니다. `儿子`, `女儿`의 儿는 얼화 대상에 넣지 않았습니다. 원본 음원과 반환된 시간 정보, 독립 음성 인식 결과를 함께 보관하며, 직접 청음 검수는 이 실행 환경에서 수행하지 못했습니다. 음성 인식 결과만으로 얼화의 발음 정확성을 보증하지 않습니다.

개발 확인: `CHROMIUM_PATH=/usr/bin/chromium python -m unittest discover -s tests -v` (Python Playwright·Chromium 필요). 기존 원본에서 전체 제작 음원을 다시 나누려면 `python scripts/build_level3_natural.py`를 실행합니다(ffmpeg 필요, 새 음성을 생성하지 않음).


## HSK 3.0 4급 신규 1000단어

- [4급 음원 학습하기](https://yanchunnu.github.io/HSK3.0-/level4.html): 검수한 4급 단어·병음·뜻·예문·예문 병음·해석을 단어장과 같은 15개 유형 순서로 제공합니다. 단어 1000개와 예문 1000개를 3급 10·11번 예문과 같은 Shuxian 목소리로 새로 제작했습니다. 반복 듣기, 속도 조절, 시작 번호 선택, 일시정지·이어듣기, 검색과 정답 숨기기를 지원합니다.
- [초록색 표지와 두 QR을 넣은 4급 단어장](HSK3.0_4급단어장_표지포함.pdf): A4 가로, 한 쪽 22단어, 표지 포함 47쪽입니다. 검수본의 본문 46쪽과 글자 크기·열 폭을 유지했습니다. 표지에는 **4급 음원 학습**과 **3급 음원 복습** QR을 각각 넣었습니다.
- [4급 표지](HSK3.0_4급단어장_표지.pdf) · [4급 학습 QR 이미지](study/HSK3.0_4급_음원_QR코드.png) · [학습 데이터](study/HSK3.0_4급_1000단어_학습데이터.json)

4급 [음원 제작·분할 정보](audio/level4-natural/manifest.json)와 원본 음원 50묶음, 대본, 독립 음성 인식 결과, 글자별 정렬 정보를 보관합니다. 한 글자 단어와 발음 주의 단어 217개는 해당 예문 속 발음에서 분리했습니다. 음원은 기기별 음성 합성으로 바뀌지 않습니다. 직접 청음 검수는 이 실행 환경에서 수행하지 못했으며, 자동 대본 대조·정렬·재생 검사는 발음과 자연스러움을 보증하는 청음 검수를 대신하지 않습니다.

저장된 원본으로 4급 음원 파일을 다시 나누려면 `python scripts/build_level4_natural.py`를 실행합니다(ffmpeg 필요, 새 음성 생성 없음). 검사 명령은 위와 같습니다.


## HSK 3.0 5급 신규 1600단어

- [5급 음원 학습하기](https://yanchunnu.github.io/HSK3.0-/level5.html): 재검수한 1,600항목을 PDF와 같은 15개 유형 순서로 제공합니다. 단어 1,600개와 예문 1,600개를 3·4급과 같은 **Shuxian – Clear & Trustworthy** 목소리로 제작했습니다. 번호·한자·병음·뜻 검색, 단어와 예문 반복 듣기, 속도 조절, 1~1600번 시작 번호 선택, 일시정지·이어듣기, 병음·뜻·해석 숨기기를 지원합니다.
- [파란색 표지와 음원 QR을 넣은 5급 단어장](HSK3.0_5급단어장_표지포함.pdf): 표지에는 **5급 1600단어 학습**과 **4급 1000단어 복습** QR을 각각 넣었습니다. A4 가로, 표지 포함 74쪽이며 본문 73쪽의 글자 크기·열 폭·내용을 유지했습니다. 본문은 한 쪽 22항목(마지막 쪽 16항목), 한자예문은 11.5pt 한 줄 배치입니다.
- [5급 표지](HSK3.0_5급단어장_표지.pdf) · [5급 음원 QR 이미지](study/HSK3.0_5급_음원_QR코드.png) · [5급 학습 데이터](study/HSK3.0_5급_1600단어_학습데이터.json)

[5급 음원 제작·분할 정보](audio/level5-natural/manifest.json)에 PCM 일치를 검증한 무손실 FLAC 원본 음원 93묶음과 3,200개 학습 음원의 연결 정보를 보관했습니다. 한 글자·다음자 등 279개 단어는 해당 예문의 발음 구간에서 분리했습니다. 원본, 제출 대본, 제공된 글자별 시간 정보, 독립 중국어 음성 인식 결과, 문맥별 정렬·구간 선정 근거를 함께 보관했습니다. 직접 청음 검수는 수행하지 못했으며 대본 대조·구간 정렬·파형·브라우저 재생 검사를 실시했습니다.

저장된 원본으로 음원을 다시 분리하려면 `python scripts/build_level5_natural.py`를 실행합니다(ffmpeg 필요, 새 음성 생성 없음). 재생 및 파일 검사는 `CHROMIUM_PATH=/usr/bin/chromium python -m unittest discover -s tests -v`로 실행합니다.

웹사이트에는 학습용 MP3·PDF·학습 데이터를 게시합니다. 보관용 원본과 분석 자료는 GitHub 저장소의 `sources` 폴더에서 제공합니다.
